Дебагыч

Как AI находит ошибку и проверяет исправление

Дебагыч получает код и требования, готовит сценарии Gherkin и автотесты, воспроизводит ошибку и проверяет исправление в изолированной копии проекта. Файлы проекта меняются только после подтверждения человека.

  • Python
  • FastAPI
  • React
  • Playwright
  • gVisor
Разобрать пример

Задача

Требование лежит в документе, тест в коде, а ошибка в отчёте без доказательства. Чтобы понять, баг это или сбой окружения, приходится всё перепроверять руками.

Хотелось, чтобы каждое требование превращалось в проверку, каждая найденная ошибка получала воспроизводимое доказательство, а исправление проверялось до того, как попадёт в код.

Одна ошибка

Демо-проект Shop API из репозитория: платёж при точном балансе.

  1. Требование становится проверкой

    Требование R1: платёж разрешён, если баланс больше суммы или равен ей. Дебагыч строит по нему сценарий и pytest-тест и запускает весь набор в одноразовой песочнице gVisor без доступа к сети.

    Требование
    R1
    Итог
    13 успешно, 1 отклонение
    Покрытие
    86,7%

  2. Ошибка получает доказательство

    Тест падает при точном балансе. Дебагыч повторяет запуск, чтобы отличить дефект от сбоя окружения, и предлагает минимальный diff: в сравнении стоит > вместо >=.

    Где
    shop.py:10
    Причина
    > вместо >=

  3. Исправление проверяется в копии

    Патч применяется к изолированной копии проекта. Проходят и исходный тест, и остальной набор. Сами файлы проекта меняются только после отдельного подтверждения.

    Набор
    14 passed, 0 failed
    Применение
    после подтверждения

Что я сделал

  • Требования с цитатами, сценарии Gherkin и тесты pytest и Playwright через структурированные ответы модели со строгой проверкой.
  • Запуск тестов в одноразовых песочницах gVisor без внешней сети.
  • Покрытие: coverage.py для Python, Istanbul с source maps для JS и TypeScript.
  • Bug Proof и Fix & Verify: повторное воспроизведение, минимальный diff и проверка на регрессии.
  • Экспорт в JUnit XML и пакет для GitHub Actions, приложение для Windows на Tauri.

AI и человек

AI пишет тесты и предлагает патч, решает человек. Код меняется только после подтверждения.

Дебагыч не выдаёт сбой окружения за дефект, останавливается на неоднозначном требовании и прямо пишет, что успешный набор не доказывает отсутствие всех ошибок.
